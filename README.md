# SecondMind — başlangıç paketi

## İlk adımlar

1. Node.js (LTS), Git ve Claude Code kurulu olsun; Claude Code'a aboneliğinle giriş yap.
2. Boş bir `secondmind` klasörü aç, bu paketin içeriğini oraya kopyala, `git init` yap ve ilk commit'i at.
3. Tasarımın orijinal HTML dosyasını repoya **koyma** (2 MB, boşuna token yer). Tarayıcıda bakmak için başka bir yerde tut.
4. Klasörde `claude` çalıştır ve şunu yaz:

   > CLAUDE.md ve docs/YOL-HARITASI.md'yi oku. Aşama 0'ı yap. Başlamadan önce planını kısaca yaz ve onayımı bekle.

5. Aşama bitince uygulamayı dene, commit at, `YOL-HARITASI.md`'de sonraki aşamayı AKTİF yap.

## İçerik

- `CLAUDE.md` — Claude Code'un her oturumda okuduğu kurallar
- `docs/` — mimari, tasarım sistemi, panel spesifikasyonları, yol haritası
- `design/referans/` — tasarım görselleri ve sadeleştirilmiş HTML'ler
- `src/renderer/public/fonts/` — Archivo (OFL)
- `resources/ai-agent/CLAUDE.md` — döküm işleyen AI ajanın kuralları
- `resources/proje-koprusu/CLAUDE-ek.md` — Runika gibi projelerin kendi CLAUDE.md'sine eklenecek köprü bölümü
